# Elgen 产品学习网站

这是一个静态学习网站，可以部署到 GitHub Pages。

## GitHub Pages 设置

1. 在 GitHub 创建一个新仓库，例如 `elgen-study-site`。
2. 上传本文件夹内的所有文件和 `assets` 文件夹。
3. 打开仓库的 `Settings` -> `Pages`。
4. `Source` 选择 `Deploy from a branch`。
5. `Branch` 选择 `main`，目录选择 `/root`，保存。
6. 等待 1-3 分钟，GitHub 会生成一个访问地址。

安卓手机可以直接用浏览器打开 GitHub Pages 地址。电脑关机后也能访问。
